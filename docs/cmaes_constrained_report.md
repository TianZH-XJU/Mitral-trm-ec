## 4. 终局判定（按预注册终止条款）

**新假设的答案：否**——约束处理 CMA-ES 找到了可行解空间（v1/v2 做不到），但找到的可行控制器**没有超过传统阈值/逻辑回归基线**。按终止条款，**当前控制器空间（17 维、5+8 特征）上的 ES 搜索就此停止**，包括约束版、多目标版、NSGA-II 等——它们攻击的是同一 17 维空间，而该空间的最优点已被传统基线更好地占据。

**合并的最终结论（入论文）**：
1. λ=0.5 标量适应度失败（收敛到激进省算解）→ 目标-判据对齐问题（机制发现）；
2. 显式约束处理修复了该问题（可行解出现，权衡改善 2.4pp）→ 但仍不敌简单基线；
3. **在当前轻量信号与两阶段控制器空间中，进化策略（三种设定）均未超越简单控制策略**——这是一个范围明确、机制清楚、可复现的负结果，与递归收益类别依赖性/修复-破坏转移等正结果共同构成论文。
