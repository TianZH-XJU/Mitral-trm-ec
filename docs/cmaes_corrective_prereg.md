# CMA-ES 纠正性实验预注册（v2，2026-10-27 冻结——最终一次运行，之后无论结果如何终止该方向）

依据：审核对 f9620be 的修正判断（两实现偏差：参数耦合 + 无组级 OOF）+ "给 ES 一次明确终点"原则。

## 1. 本次纠正的范围（仅限以下三项，不做其它变更）

1. **参数维度修正**：控制器空间 = Gate1 (w1:5 + b1 + tau1) + Gate2 (w2:8 + b2 + tau2) = **17 维**。b2 与 tau2 独立索引（修复 f9620be 中 theta[15] 双绑定缺陷）。
2. **适应度组级 OOF 重登记**：适应度在 gate_train 的**组级 K=5 折外**评估——每个候选 θ 在折 f 外样本上的策略效果由 θ 直接给出（θ 是无标签拟合的搜索变量，组折的意义在于防止同一批样本的 EM 观测被重复利用产生选择偏差）：F(θ) = mean over folds-seeds [折外样本的 EM − λ·N_cell/N_cell_ref]。**N_cell_ref 从冻结配置载入**（`gate_03c1v2/r2_baseline_matched.json` 各种子 best_fixed 的 gate_train 成本），不用 validation 重新挑选。
3. **数据使用规则**：适应度 = 仅 gate_train（组级 OOF）；validation 只用于最终一次候选对照（与传统基线的已冻结数字并列报告，**不做选择**——ES 与基线的比较在预注册判据下直接判定）；gate_confirm 与 COGS test 不参与。

## 3. 成功标准（预注册，不变）

- 效率路径：validation 上 EM 差 group-bootstrap 95% CI 下界 ≥ −0.5pp 且 N_cell 减 ≥30%；
