# Gate 与新保留集设计（Design v0.1，2026-10-25——仅设计，不训练）

依据：阶段七发现 2→3 深度破坏率 4.7–13.9%、修复率随深度递减——"何时停止"成为真问题。本设计冻结以下要素；训练与确认性评估待审核批准。

## 1. 预测目标（两个，明确分开，不得混用）

- **目标 A（序列级）**：给定当前深度的完整序列状态（已知预测文本+内部信号），预测"再做一次递归后该序列的 EM 变化方向"（修复/保持/破坏 三分类；或修复 vs 破坏 二分类）。服务于"每序列选深度"策略。
- **目标 B（token 级）**：预测下一 token 位置在下一深度的修复/破坏。服务于逐步计算分配。**与目标 A 分别训练、分别评估。**
- 标签来源：相邻深度转移的四类计数（序列级）/ 逐 token 对位变化（token 级），从已持久化 dump 的可复现管线生成。

## 2. 候选特征（不预设有效）

k 深度处的：top-1 概率、top-2 margin、预测分布熵、相邻深度分布变化 Δp、隐状态变化 ‖Δz‖、预测稳定性（相邻深度 argmax 是否改变）、深度指示、（序列级另加）当前预测长度与已用递归次数。全部标准化；AUC/PR-AUC + 类样本数 + 按指令组 bootstrap CI（沿用协议 §7.3）。此前 SCAN 上 AUC 跨种子不稳（0.28–0.88、harm 9–96 例）是已知风险，设计目标即检验在错误更丰富的 COGS 上是否成立。

## 3. 数据划分（防泄漏，预冻结）

**COGS gen 已解封，不得用于 gate 训练/验证/最终确认。** 方案：

- **Gate-H（新保留集，从 COGS train 派生）**：在重训基础模型**之前**冻结划分——按指令组从 COGS train 抽 10% 指令组为 Gate-Holdout（不进入任何基础模型训练、不参与特征/阈值选择）；其余 90% 已在当前 checkpoint 训练中（现有 R1/R2 的训练集），因此：
  - Gate 训练/验证数据只能来自**现有模型已训练的 train 内部**（在训练分布内做 gate 的拟合是可行的，因为 gate 标签是相邻深度转移而非 gold 正确性泄漏——但必须在设计审查时确认这一点）。
  - **独立确认**：Gate-Holdout 的基础模型需用 90% train 重训（3 种子，预注册），gate 在其上做一次性确认。
- 备选：SCAN 全划分因 test 已用尽，只能作跨数据集参考而非确认集；CFQ 维持冻结（解冻需独立批准）。

## 4. 对照与主指标（预冻结）

同一基础模型（Gate-Holdout 版 R1/R2，3 种子）：
1. 固定 extra=0 / 1 / 2 / 3（四条基线）；
2. 阈值 gate（每特征单变量阈值，在 gate 验证集选）；
3. 学习 gate（逻辑回归，候选特征全部输入；仅目标 A）；
4. 主指标：**完整序列 EM**（确认集）+ 平均额外递归次数 → 报告 accuracy–compute Pareto。gate 的价值判定：在不损失 EM（≤0.5pp）的前提下减少 ≥30% 额外调用，或提升 EM ≥1pp。
- 所有阈值/特征选择只使用 gate 训练/验证部分；确认集一次性评估。

## 5. 明确禁止与风险

- 不使用 gen 的任何预测/分数做 gate 选择或"确认"。
- 教师强制与自由生成轨迹分开（gate 在自由生成轨迹上训练与评估；教师强制仅作诊断）。
- 已知风险：COGS train 内部错误率低（深度 1+ 后 ~96-99%），修复/破坏事件可能稀少，gate 标签失衡——若 gate 验证集上破坏事件 <100/种子，明确报告证据不足，不强行宣称 gate 有效。
