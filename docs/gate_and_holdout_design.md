# Gate 与新保留集设计（v0.2，2026-10-25——仅设计，不训练；v0.1 已按阶段九审核重写）

修订要点（对照审核四问题）：① out-of-sample 划分（基础模型只训 base-train，gate 的训练/验证/确认全部用各自 out-of-sample 组的轨迹）；② 执行语义与真实成本统计（浅层生成→gate 决策→深度重生成，成本全计）；③ token 级标签对齐规则（显式定义+可靠性验证）；④ 统计判据（分组配对 bootstrap + 不确定判定 + 证据不足门槛保留）。

## 1. 组划分（v0.2 核心修订，重训前冻结）

- **分组键**：COGS train 的每个样本按其**句子结构模板**分组——可复算定义为：输入句子的**非实体词序列**（实体词 = 首字母大写 token / 专名；非实体词 = 句法功能词与动词）小写化后拼接。同组样本共享句法模板但实体不同。此键防止"相同结构模板跨分区泄漏"（比逐行随机更严格）。
- **比例**：base-train 70% / gate-train 10% / gate-validation 10% / gate-confirm 10%（按模板组分配，固定种子 0，`scripts/freeze_gate_split.py` 一次生成并 commit；划分清单 SHA-256 归档）。
- **基础模型**：R1、R2 各 3 种子，**只在 base-train 上训练**（6 个重训，预注册配置同现有）。gate 的所有特征轨迹均由该模型在**未参与其训练**的组上生成——训练/验证/确认三组的特征生成条件一致（全部 out-of-sample），消除 v0.1 的分布不匹配（gate 特征不再来自基础模型已记忆的样本）。
- COGS gen 与官方 test.tsv 维持封存，不用于 gate 任何环节。

## 2. 预测目标与执行语义（v0.2 明确）

**目标 A（序列级，主目标）——估计继续计算的期望收益并选择最终深度**（非单步转移预测）：
- 决策时机：extra=0 完成一次自由生成（浅层序列 S0 + 内部信号）→ gate 读取 S0 聚合特征 → 动作 ∈ {停在 e0, 继续至 e1}；若继续，e1 生成后再决定 {停, 继续至 e3}（决策点=2，与已评估深度网格一致）。
- **执行语义（成本全计）**：继续 = **从编码状态重新自由生成**（不假设复用浅层解码状态）——总成本 = 浅层生成 + gate 前向 + 深层重新生成。compute 指标为**总生成步数**（含重复生成部分），非仅"额外递归调用数"。
- 训练标签：预计算该样本 e0/e1/e3 的 EM，Oracle 动作 = 最小 EM 损失下的最低成本选择；gate 推理时只用 §3 特征（无 gold）。
- 单步"保持"歧义的处理：不混用标签——以最终 EM+成本定义动作价值，绕开"保持=正确保持还是错误保持"的歧义（审核问题 2 的第二点）。

**目标 B（token 级，次目标，仅在对齐验证通过后实施）**：
- **对齐规则（显式）**：两个深度的自由生成仅在**共同前缀**内按位置对齐（到首个分歧 token 为止）；分歧后不配对（长度/EOS 不同的位置无法可靠对位）。标签仅在前缀内生成。
- **可靠性验证（预注册）**：gate-train 上人工抽检 100 个前缀对齐样本，>10% 对齐错误则目标 B 判不可靠并放弃。teacher-forced 轨迹仅作诊断，不作目标 B 训练标签。

## 3. 特征（不预设有效）

序列级（决策点聚合）：当前深度输出的平均/最小 top-1 概率与 margin、平均熵、预测长度、EOS 是否提前、（第二决策点）相对浅层输出的 Δp 聚合、已用额外递归数。评估：AUC/PR-AUC + 类样本数 + 按模板组 bootstrap 95% CI。已知风险（SCAN 上 AUC 0.28–0.88 不稳、harm 样本稀少）写入报告。

## 4. 对照与判据（v0.2 统计修订）

对照（同一 base-train 模型，gate-confirm 一次性评估）：固定 e0 / e1 / e3、阈值 gate（gate-validation 选）、逻辑回归 gate（gate-train 训练）。

**主指标**：gate-confirm 完整序列 EM + 总生成步数 → Pareto。

**预注册判定（v0.2）**：
- gate 有价值 ⇔ 相对最优固定深度：EM 差的**按模板组配对 bootstrap 95% CI**（1000 次）完全 ≥ −0.5pp 且总生成步数减少 ≥30%；或 EM 差 CI 完全 ≥ +1pp。
- **不确定判定**：CI 同时容许 ≥+1pp 与 ≥−1pp → 判"不确定"，不宣称有效。
- **证据不足门槛保留**：gate-train/validation 破坏类事件 <100/种子 → 报告证据不足（不因结果好看取消）。
- 3 种子为初步确认，不宣称强显著。

## 5. 禁止与冻结

不使用 gen/test.tsv；gate 选择只用 gate-train/validation；teacher-forced 仅诊断；CFQ 冻结；GA/CMA-ES 冻结（gate 用逻辑回归与阈值）；本版**不含任何训练**。
