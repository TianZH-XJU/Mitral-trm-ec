- **R2**：e0 已 90–93% 正确，必要继续仅 3.5–6.2%，有害继续 0.1–0.5%。**理论最优 gate 的可省空间存在但极小**：oracle 完美分类下最多比固定 e3 省 ~93% 的 N_cell 同时 EM 持平（停在 e0 的 e0-correct 样本 + 继续的少量），比固定 e0 多 ~4pp EM。

## 4. EM–成本关系：必要 vs 有害继续

| 配置 | 必要继续（e0错→e3对） | 有害继续（e0对→e3错） | e0 正确数 |
|---|---|---|---|
| R1_s0/s1/s2 | 93.8% / 96.6% / 96.1% | **0.000% × 3** | 0 / 0 / 0 |
| R2_s0/s1/s2 | 4.2% / 3.5% / 6.2% | 0.1% / 0.5% / 0.2% | 2,187 / 2,242 / 2,181 |

**核心结论**：
1. **R1 的 gate 问题不成立**：e0 永远全错（final-only 监督产物），"何时停"在 e0 处无决策空间；唯一可优化点是 e1→e3，其最优收益也只是把 N_cell 从 ~380 降到 ~370（~3%），远低于任何路径的成功阈值。
2. **R2 的 gate 问题成立但天花板极低**：完美 oracle 下省 ~90% 计算（393→~110 N_cell）+ EM +4pp（e0 0.906→oracle 混合 ~0.947）。**但单信号 AUC 仅 0.47–0.58**——特征几乎不含区分信息，因为 e0 错误的样本（低频词、复杂结构）与 e0 正确的样本在浅层置信度上分布几乎重叠。

## 5. 判定：CMA-ES 是否值得跑？

按审核分支规则——**"若特征诊断表明信号基本不含有效信息，则不应在同一特征空间扩大搜索"**：

- **R1**：问题不成立（无决策空间），CMA-ES 搜索无意义——任何优化器都会学"总继续"，与固定 e3 的差异仅剩 e1 轮的 ~3% 计算 shaving，且伴 EM 风险。
- **R2**：问题成立但特征信息量不足（AUC 0.47–0.58，跨种子不稳定）。CMA-ES 直接以 EM+成本为适应度虽可绕开类别失衡标签，**但适应度景观由同样的 6 个信号张成**——如果信号本身区分不了必要/有害继续，进化搜索找到的边界将与逻辑回归一样退化为多数类，或过拟合开发组的偶然模式。
- **建议（供审核裁决）**：
  - 路径 α：**不启动当前特征空间上的 CMA-ES**（任务 03 的前提"信号具备一定决策信息"未满足——R2 的 AUC <0.6 且不稳定；R1 无决策空间）；
  - 路径 β：若仍需检验"进化优化器 vs 逻辑回归"的方法学问题，可只对 **R2** 跑一个最小预算 CMA-ES（预期结果：退化为多数类/过拟合，作为方法学负面证据入档）；
  - 路径 γ：先重新设计状态信号（如 e0/e1 预测的 token 级不一致度、与训练分布的结构相似度特征），单独验证信息量后再上优化器。
