# 03A/03B：轨迹修复与修正版信号诊断（2026-10-26，无新训练）

## 03A：轨迹生成器修复（`scripts/gate_gen_trajectories_v2.py`）

修复审核发现的三个缺陷：
1. **n_gen 逐样本化**（原为 batch 级共享计数，同 batch 样本被强加相同生成长度）；
2. **EOS 后信号屏蔽**（active mask：完成样本不再累计 top1/margin/熵/dz，分母为逐样本有效步数）；
3. 回归测试：**6/6 模型 PASS**——同一样本单独解码 vs 混合 batch 解码，预测、有效长度、四路信号全部一致（<1e-5）。

旧轨迹保留为 `runs/gate_exp/traj/`（历史），新轨迹 `runs/gate_exp/traj_v2/`（18 文件）。六个 base checkpoint 冻结未动。

## 03B：修正版诊断结果（仅 gate_train/gate_validation）

### 1. oracle 分布（不变，EM 无 pad 影响）

R1: e0 EM=0.000（三种子），oracle 继续 92.5–96.6%；R2: e0 EM 90.3–92.8%，oracle 继续 3.5–9.8%（停 93.5–96.4%）。

### 2. 关键反转：R2 的信号具有强判别力（旧结论作废）

**Gate1 单信号（validation，ROC-AUC/PR-AUC，三种子均值）**：

| 信号 | R1 | R2 |
|---|---|---|
| top1 | 0.519 / 0.958 | **0.091 / 0.026** |
| margin | 0.520 / 0.958 | **0.094 / 0.026** |
| entropy | 0.477 / 0.950 | **0.886 / 0.216** |
| n_gen | 0.430 / 0.939 | **0.760 / 0.214** |

R2 的 top1/margin 的 AUC **远低于 0.5**——置信度越高越**不该**继续（e0 已对的样本置信度高）；entropy 与 n_gen 的 AUC **0.89/0.76**（方向：越混乱/越长越该继续）。**旧诊断的 0.47–0.58 是缺陷信号污染的结果**——修复后 R2 有一个信息量充足、方向明确的信号结构。

**组合特征（6 特征逻辑回归，validation 上组级 5-fold CV）**：
- R2：**AUC 0.894 / 0.919 / 0.894（三种子），均值 0.904**——稳定且强；
- R1：0.578–0.696（均值 0.632）——仍弱（R1 的 e0 全错，本就无区分对象）。

### 3. 修正 OOF Gate1 动作与 g2_train_n

| 配置 | OOF 继续率 | g2_train_n | 正类召回@0.5 |
|---|---|---|---|
| R1_s0/1/2 | 1.000/1.000/0.999 | 2,416/2,417/2,415 | ~1.000 |
| R2_s0 | **0.004** | **10** | 0.005 |
| R2_s1 | **0.009** | **22** | 0.030 |
| R2_s2 | **0.014** | **33** | 0.038 |

R2 的 g2_train_n 从 0 → **10–33**（修复后少量正类被召回，不再是空集），但**默认阈值 0.5 下正类召回仍极低（0.5–3.8%）**——问题从"零样本"变为"阈值与损失函数不适合稀有正类"：组均衡逻辑回归的决策边界偏向多数类，**这是可通过 PR-导向阈值/类权重修正的机制问题，而非信号无信息**。

### 4. 判定（修正 03B 的结论，推翻旧任务 02）

1. **旧结论"信号信息量不足"对 R2 不成立**：修复后 R2 组合特征 AUC 0.904（三种子 0.894–0.919 稳定），entropy/n_gen 单信号 0.89/0.76——**信号存在且可重复**。旧诊断的失败部分归因于轨迹缺陷（EOS 后污染 + batch 级 n_gen），部分归因于逻辑回归在稀有正类下的阈值/损失失配。
2. **R1 的结论维持**：e0 全错（有害继续=0），e0 处无决策空间；其弱 AUC（0.58–0.70）无关紧要。
3. **CMA-ES 的前提（"可重复的判别增益"）在 R2 上现已满足**（AUC 0.904 > 显著阈值且跨种子稳定）；但直接收益估计仍受天花板限制（R2 oracle 完美下省 ~90% N_cell + EM +4pp；实际可用增益取决于 rare-positive 的召回-精度曲线）。
4. **决策建议**：路径 γ 的"重新设计状态信号"对 R2 **不再必要**（现有 6 信号组合已具 0.9 AUC）；下一步合理选项：(a) 用修正阈值/类权重的逻辑回归（正类召回导向）先兑现信号价值；(b) 启动受控 CMA-ES（以 EM+成本为适应度，绕开阈值失配）。两者都待审核裁决。**旧 gate_confirm 已用尽**——确认性评估需新的独立 holdout。
