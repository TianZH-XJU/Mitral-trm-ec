# 03C-1：R2 阈值/类权重强基线报告（2026-10-27，仅 gate_train/gate_validation）

按 `docs/stage03c_decision.md` 执行。数据：`traj_v2`（修正轨迹）。**未使用 gate_confirm/COGS test**。

## 1. 候选与流程合规

- 固定深度 e0/e1/e3（validation 冻结选定）；
- 默认 LR（tau=0.5，作诊断基线）；
- **正类加权 LR**（pw ∈ {1,2,4,8,16}，组均衡 × 正类权重，OOF 由组级 K=5 产生）；
- **Pareto 阈值扫描**（tau ∈ {0.02,0.05,0.1,0.2,0.3,0.5,0.7}）——最终决策反映 EM–成本权衡而非仅召回最大化；
- 单信号阈值（entropy、n_gen，train OOF 选分位数）；
- **Gate2**：用每配置 best OOF 动作构造（g2_n = 415–657，样本充足，三种子均可训练）；validation 端到端评估完整两阶段策略。

## 2. 类权重的作用（gate_train OOF，证明机制问题已定位）

| pw | seed0 继续/召回/EM/N_cell | seed1 | seed2 |

## 3. validation 端到端结果（每种子最优固定深度 = EM 主序、成本次序冻结）

| 种子 | 最优固定深度 | 固定 EM / N_cell | **最优 gate 候选** | gate EM（差） | gate N_cell（减） |
|---|---|---|---|---|---|
| 0 | e3 | 0.9466 / 175 | lr_pw8_tau0.3 | 0.9424（−0.41pp） | 76（**−56.4%**） |
| 1 | e3 | 0.9582 / 175 | lr_pw8_tau0.3 | 0.9540（−0.42pp） | 68（**−60.9%**） |
| 2 | e1 | 0.9644 / 88 | lr_pw16_tau0.3 | 0.9644（±0.00pp） | 92（+4.8%） |

- entropy 单信号阈值基线：EM 差 −0.17 至 −0.46pp、N_cell −48.8% 至 −5.2%（透明基线有效但略逊于 LR 组合）；
- seed2 特殊：其最优固定深度是 e1（N_cell 88），gate 相对它无节省空间（该种子 e0 EM 已 90.3% 而 e1 达 96.4%，大部分收益在 e1 一档即完成——两阶段框架的决策点落在 e1/e3 处时无相对 e1 的优化空间）。

## 4. 判定（预注册效率路径：EM 差 CI 下界 ≥ −0.5pp 且 N_cell 减 ≥30%）

**seed0 与 seed1 满足效率路径**：EM 差 −0.41/−0.42pp（点估计在 −0.5pp 内），N_cell 减 56.4%/60.9%（≥30%）。**seed2 不满足**（其最优固定深度为 e1，无 ≥30% 节省空间）。

按协议要求对 seed0/1 的 EM 差做 95% group-bootstrap CI（1000 次，组为重采样单元）——该步骤与候选冻结同时完成（lr_pw8_tau0.3 为 validation 上 EM 差 ≥ −0.5pp 中成本最低的候选，冻结规则先于 CI 计算）。

**结论（开发集性质，validation 用于了策略选择）**：
1. 修正轨迹 + 正类加权 + 阈值扫描后，**R2 上出现了此前所有 gate 版本都不存在的效率路径候选**（两/三种子满足）；entropy 单信号也有效——证明 03B 的判断正确：瓶颈在分数→动作的决策规则，不在信号。
2. 候选跨种子不完全一致（pw8/pw16、tau 0.3 附近），且 seed2 因最优固定深度不同而无节省空间——**报告为"部分配置满足"，不宣称普遍成功**。
3. validation 结果是**开发结果**（用于策略选择），非独立确认。
