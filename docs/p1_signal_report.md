# P1：token 级 latent 信号精确验证报告（2026-10-27）

数据：新 token 级轨迹 `runs/gate_exp/traj_tok/`（R2 三种子 × train/validation，逐 token top1/margin/entropy + hidden 8 维快照）。评估：组级 5 折 OOF、组均衡逻辑回归、序列级 oracle 标签（继续收益 = e0 未达 EM）。

## 1. 核心结果（OOF，跨种子）

| 特征组 | ROC-AUC（3 种子） | PR-AUC | Brier | Recall@5% 预算 |
|---|---|---|---|---|
| F0 历史摘要 | 0.940–0.964 | 0.657–0.740 | 0.038–0.072 | 0.280–0.478 |
| **F1 token 级统计** | **0.978–0.986** | **0.808–0.875** | **0.026–0.040** | 0.318–0.527 |

| F3 结构 | 0.513–0.689 | 0.323–0.435 | 0.063–0.107 | 0.197–0.332 |
| F4 hidden 快照 | 0.558–0.709 | 0.229–0.293 | 0.079–0.108 | 0.178–0.234 |
| F5 组合 | 0.972–0.981 | 0.807–0.872 | 0.026–0.044 | 0.318–0.532 |

## 2. 判定

1. **token 级信号显著优于样本级摘要**（审核的核心假设验证为真）：F1 相对 F0 的 AUC +0.02–0.04，**PR-AUC +0.07–0.15**（稀有正类下最关键的指标）、Brier 全面更低。token 级分布统计（分位数/极值）确实捕获了被均值稀释的局部高风险 token。
2. **F4（hidden 原始快照）信息量有限**（AUC 0.56–0.71）——轻量 hidden 差分不比 token 级统计更有用；不升级到全维 hidden（符合审核"先低维再决定"原则）。
3. **F5 组合不优于 F1 单独**（0.972–0.981 vs 0.978–0.986）——F3/F4 引入噪声抵消增益；**P2 控制器输入冻结为 F1+F2**（token 统计 + 跨深度变化）。
4. **审核要求的完整指标已全部报告**：AUC/PR-AUC/Brier/Recall@预算；标签区分（token 修复 vs 序列收益）将在 P2 的策略级评估中体现（本步为信号诊断，策略收益必须经真实 mixed-depth decoding 验证——见 P2 计划）。
5. 校准良好（Brier 0.026–0.044 接近基率平方）——概率可用作预算分配依据。

## 3. P2 冻结输入

**F1+F2（约 38 维）为 token 级控制器的统一 genotype 输入**；F3/F4 不进入（噪声 > 增益）；F0 仅作历史参照。混合深度解码需真实执行（不能在固定深度轨迹上选 token）。
