## 3. 判定（诚实）

1. **e0 错误可排序（P1 原发现保留），但"继续有益 vs 继续有害"不可判别**：Gate0 的 benefit-vs-harm AUC 跨种子 0.49–0.70 且 PR-AUC 接近基率——现有信号无法在正类率 96%+ 的失衡下区分 repair 与 harm；
2. **Gate1 的二段收益样本极少（n=16–32）**——任何统计结论不可靠；
3. **机制解释**：repair:harm = 20–70:1 的结构不对称意味着 **"总停"策略的 EM 损失上限就是 repair 率（~5–9%）**，而"总继续"的额外成本是每 token 多 3 次 refinement。因此真实的优化问题不是"区分 repair/harm"，而是**在 e0 置信度足够高的样本上提前停**（preserve 类，88% 的样本）——这类"何时停是安全的"判别 P1 已证明可排序（F1 PR-AUC 0.81–0.88 预测 e0 正确性）；
4. **对 P2-R 的指导**：因果 Gate0 特征应预测 **"e0 输出是否正确"**（preserve 判别，样本充足且可排序），而非 repair-vs-harm（不可判别）；Gate1 用 e1 信号预测"e1 是否正确"。这是审计后修正的标签语义——与 causal decoder 的实际决策语义一致（停 = 接受当前深度输出）。

## 4. 修正后的 P2-R 标签协议

- Gate0 标签：`em_e0 == 1`（停是安全的）vs `em_e0 == 0`（停会损失 repair 机会）；
- Gate1 标签：`em_e1 == 1` vs `em_e1 == 0`；
- 成本计入实际 refinement 调用数（causal decoder 单元测试保证）；
- F2 特征废弃（审计指出其跨独立轨迹比较无因果意义），改为同一状态下的 e0→e1 变化（Gate1 时刻允许）。
