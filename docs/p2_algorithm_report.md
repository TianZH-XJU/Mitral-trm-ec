# P2：token 级连续控制器的算法比较报告（2026-10-28，总 23h 计算）

设计：统一 38 维 genotype（F1+F2 输入，两段式 token 级控制器）、真实混合深度解码、组级嵌套（外层折 4 留出，内层 4 折搜索，适应度=400 样本子集上的可行性优先 EM 约束 + N_cell）、统一 rollout 预算（pop16×20 代 = 336 rollouts/算法/种子）、单优化器种子/模型种子。

## 2. 判定

1. **MGA（Microbial GA）最稳定**：唯一 3/3 外层可行的算法，s0/s1 EM 零损失且 N_cell 0.43/0.27——其成对竞争+基因块传播在中等预算（336 rollouts）下最有效；
2. **DE 是最强激进省算者**：三种子全部可行且 0.25–0.50 N_cell（最深的节省），EM 损失全部 ≤0.41pp——DE 的差分探索在"可行区内压成本"上表现突出；
3. **sep-CMA-ES 单点最高**（s0 +0.21pp/0.385）但跨种子不稳（s1 −1.18pp）；full CMA-ES 不稳定（38 维下协方差学习 336 rollouts 预算不足）；
4. **(1+1)-ES 最弱**：可行率 1/3——预算不足时局部爬山易陷在违反约束区域；
5. **对比 P0 审计要点**：token 级控制器整体上**首次大规模超越旧样本级 gate**——旧样本级最优（约束 CMA-ES 0.584×/−0.29pp、传统基线 0.475×/−0.12pp）在嵌套外层评估下没有一个通过；新 MGA/DE 在三种子中 3/3 可行。**问题表示方式（token 级 vs 样本级）是主要瓶颈的假设被验证**。

## 3. 诚实边界

- 单优化器种子（预算受限）——算法间差异需在 P4/P5 多种子确认；
- 外层为单折（fold 4 留出，其余为内层）——完整 5 折外层受计算限制，如实记录；
- s2 的参照基线是 e3（其内层 EM 主序），s2 各算法 N_cell 比 ~0.5 与 s0/s1 的差异来自种子本身特性；
- GA/sepCMA 在 s2 收敛到"全继续"解（N_cell≈1.0）——不可行方向，如实报告。

## 4. P3+ 计划

固定结构线性 token gate 已被证明有效（MGA/DE），P3（NEAT/GP 可变结构）检验"表达能力是否仍是瓶颈"；P4 多目标（NSGA-II/MO-CMA-ES/MO-DE）在 MGA/DE 的 Pareto 区域上细化；P5 跨类别 LOCO 验证稳健性。
