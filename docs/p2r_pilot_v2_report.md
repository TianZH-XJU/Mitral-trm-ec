## 判定

1. **真实因果节省确认**：三种优化器在留出折上均以 ~0.256 N_cell（即 ~74% 递归计算节省）达到固定 e3 的 EM（差 0.16–0.31pp，容差内）。这是 P2-R 以来第一个计数精确、无 look-ahead、外层一次性评估的正面结果。
2. **算法间无分离**：三者在 336 预算下收敛到几乎相同的解（0.2626–0.2627），仅比预登记阈值策略（0.266）改进约 0.4%（相对）。这提示该问题的主要结构已由简单阈值捕捉，优化器边际收益有限。
3. **单种子限定**：1 模型 seed × 1 optimizer seed 的 pilot 不支持任何算法优劣结论；扩展与否按裁决留给后续决定。
4. 过程记录：GA 首轮因硬编码基准 bug（max(e3em, 0.8789) 把真实 0.8633 抬高）白跑 4.8h；该 bug 已修复并在内层折子集上独立复诊（thr(0.85,0.90) 与 e3 完全持平 @ 0.266）。两次保存崩溃（无可行解未处理、numpy 真值歧义）均已修复并加入增量检查点——响应了"中断不得丢结果"的要求。
