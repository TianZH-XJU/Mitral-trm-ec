# P3：可变结构 token 控制器报告（2026-10-28，4.3h）

设计：RuleGA（8 条可解释条件规则，MGA 式演化）与 MLP-GA（14->12->1 非线性 + 连接掩码稀疏化），复杂度惩罚 λ_c=0.02，与 P2 完全相同的嵌套评估/预算（336 rollouts）。

## 结果（外层折，EM 差 pp / N_cell 比）

| 结构 | s0 | s1 | s2 |
|---|---|---|---|
| RuleGA | **+0.00 / 0.253** | −0.59 / 0.254 | −0.47 / 0.503 |
| MLP-GA | **+0.41 / 0.500** | **+0.00 / 0.500** | −0.23 / 0.500 |

## 判定

1. **RuleGA 在 s0/s1 上实现了全场最深的省算（N_cell 0.253–0.254）**，s0 EM 零损失、s1 −0.59pp（略超容限）——比 P2 的 DE（0.253–0.265）同等省算但 s0 无损；规则集 8 条、完全可解释（特征阈值 + 方向 + 动作）；
2. **MLP-GA 三种子 EM 差全部 ≥ −0.23pp**（s0 甚至 +0.41pp），但省算卡在 0.50——非线性表达改善了 EM 保持但未进一步省算；有效连接约 84/168（稀疏化生效）；
3. **对"表达能力是否瓶颈"的回答**：部分是——可变结构相对 P2 线性控制器的增益集中在 **EM 保持**（MLP-GA 零损失三种子）与**更深省算**（RuleGA 0.25）两个维度上，但两者未同时达到（RuleGA s1/s2 超容限、MLP-GA 省算浅）。**固定线性不是完全瓶颈，但可变结构拓宽了 Pareto 前沿**——这正是 P4 多目标搜索的动机。
4. 复杂度惩罚有效：规则数收敛至 8（上限内），无爆炸。
