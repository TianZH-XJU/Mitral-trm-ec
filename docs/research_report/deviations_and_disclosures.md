## 4. 运行事故与恢复

- P2-R-1/P3-R 全部长任务采用增量原子检查点（每 32-64 评估）+ run manifest
  + 断点续跑；全程 6 次进程崩溃/中断，**零结果损失**（均有检查点或可跳过重跑）；
- P3-R-1 采用双进程并行（s0 与 s1/s2 分离 run_id），结果按 glob 聚合。

## 5. 统计口径

- 非劣效界：EM 差 >= -0.5pp（点估计与 LCB95 双报告）；
- bootstrap：P2-R 用 1,000 次，P3-R-3 按预注册升到 20,000 次（固定种子）；
  bootstrap 次数只降低 Monte Carlo 误差，不增加独立样本；
- 所有 CI 为 group-cluster（按结构组重采样），非逐样本 iid。
