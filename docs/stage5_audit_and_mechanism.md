## 二、结构类零分的格式性排查（排除技术解释）

直接检查 R1_s1@e3 在 cp_recursion 的原始预测（3 例）：
- 预测结构与 gold **同型**（角色谓词序列正确，如 `value . agent ( x _ 2 , x _ 1 ) AND value . ccomp (...)`），失败点为：
  1. **变量索引计数错误**（`x _ 15` vs `x _ 28`；`x _ 14` vs `x _ 21`；`x _ 8` vs `x _ 7`）——深嵌套需要跨从句精确跟踪实体索引；
  2. **长度截断**（hyp 200 vs gold 272/341 token）——结构类样本最长（gen 最长 480 token 全在此类）。
- 类别标签映射正确（21 类计数均为 1,000，与官方标注一致）。
- **结论：结构类零分是真实的模型能力失败（变量索引跟踪 + 深嵌套长度），非格式/标签/评估错误。** 与 Lindemann et al. (ACL 2023) 用显式排列预测解决结构泛化的思路对照，当前隐式递归不含指针/索引机制，失败模式与预期一致。

## 三、机制诊断：深度 0→3 的逐类别修复/破坏（free-running，R1，3 种子合计 63,000 样本）

四类序列级转移（e0 预测 vs e3 预测，均对同一 gold）：

| 类别（按修复率排序） | repaired | broken | wrong→wrong |
|---|---|---|---|
| active_to_passive | **94.0%** | 0.0% | 6.0% |
| only_seen_as_unacc_subj_as_obj_omitted_transitive_subj | 88.7% | 0.0% | 11.3% |
| only_seen_as_unacc_subj_as_unerg_subj | 88.6% | 0.0% | 11.4% |
| do_dative_to_pp_dative | 77.8% | 0.0% | 22.2% |
| obj_omitted_transitive_to_transitive | 57.2% | 0.0% | 42.8% |
| subj_to_obj_common | 49.9% | 0.0% | 50.1% |
| ...（中间 8 类 2.8–48.9%） | | | |
| passive_to_active | 20.5% | 0.0% | 79.5% |
| prim_to_* / pp_/cp_recursion / obj_pp_to_subj_pp | 0–2.8% | 0.0% | 97–100% |
| **总体** | **31.4%** | **0.0%** | **68.6%** |

**三个机制发现**：
1. **序列级 broken = 0.0%（全部 21 类 × 3 种子）**：从 e0 到 e3 没有一个样本从正确变错误——在 COGS gen 上，R1 的额外递归**只会修复不会破坏**（序列级）。passive_to_active 的 −17.7pp（vs E0W）是"E0W 能对而 R1 修复不到"的相对劣势，不是递归把对的改错。
2. **修复率按泛化类型分层**：论元结构交替类（active_to_passive 94%、dative 78%、作格交替 ~89%）> 实体角色重映射类（subj_to_obj 50%）> 新词汇暴露类（prim_to_* ≤3%）> 结构递归类（0%）。递归修复的是**训练中见过的语法模式在新词汇组合上的重放**，而非需要新计算机制（索引/指针）的结构泛化。
3. **E0W 的相对优势集中区**（passive_to_active）提示：非递归模型偶而直接命中的模式，递归模型的中间表示反而锁定到错误轨道——但这类"递归伤害"在 free-running 序列级上从未表现为对→错（broken=0），只表现为修复失败。

## 四、研究主张的准确定位（对照现有工作）

**可作确认性结论的**（预指定比较、参数匹配、3 种子方向一致）：
> 在参数量匹配（±0.51%）的轻量级 GRU Seq2Seq 上，final-only 监督的共享权重递归模型（R1）在 COGS 组合泛化集上比非递归基线高 +10.7pp（3 种子方向一致），收益完全来自词汇泛化类别；序列级上额外递归零破坏（broken=0/63,000）。

**必须如实报告的限制**：
- 结构泛化 3 类全零（所有模型），且失败模式明确（变量索引跟踪 + 嵌套长度）；
- 三种子幅度不均（+0.7 ~ +17.3pp），R1 seed 0 近乎无优势；
- R2 深度非单调（e2 31.5% > e3 29.9%）——"循环越多越好"不成立；
- gen 已解封使用，gate 类后续实验不能再以 gen 为独立确认集。

**探索性假设（利用已解封 gen 得出，需新数据确认）**：
- 递归收益由泛化类型决定：可修复类 = 训练语法模式的新词汇重放；不可修复类 = 需要训练中缺失的计算机制。
- 与 Think-at-Hard / Loop-Think-Generalize 的差异定位：我们不主张"发现 overthinking/动态递归有用"，而是**在参数受限小模型上刻画递归收益的类别依赖边界**——这在该文献线上是未被系统回答的问题。
