## 1. 任务 1：相邻深度序列级转移（真实分母，`results/cogs_adjacent_depth_transitions.csv`）

**关键发现：序列级破坏（correct→wrong）确实存在**——阶段五的"零破坏"是分母为零造成的假象（R1@e0 无正确样本时 0→1 的 HarmRate 分母为 0，此前统计把它算成了 0%）：

| 模型 | 转移 | cw(破坏) | wc(修复) | 起始正确数 | HarmRate |
|---|---|---|---|---|---|
| R1 (s0/1/2) | 0→1 | 0/0/0 | 1338/1/4038 | 0 | **NA**（分母=0） |
| R1 | 1→2 | 63/0/77 | 3865/4932/4405 | 1338/1/4038 | 4.7% / 0% / 1.9% |
| R1 | 2→3 | **717/234/928** | 555/1856/782 | 5140/4933/8366 | **13.9% / 4.7% / 11.1%** |
| R2 | 0→1 | 5/13/3 | 5211/4761/5995 | 624/863/1287 | 0.8% / 1.5% / 0.2% |
| R2 | 1→2 | 262/207/368 | 299/676/974 | 5830/5611/7279 | 4.5% / 3.7% / 5.1% |
| R2 | 2→3 | 436/302/705 | 58/189/195 | 5867/6080/7885 | 7.4% / 5.0% / 8.9% |

**修订后的机制结论**：
1. **额外递归既修复也破坏**：随深度增加，HarmRate 上升（R1 2→3 达 4.7–13.9%）而修复率下降——深度收益递减、风险递增，解释了 R1 e2→e3 增益放缓与 R2 的 e3 回退。
2. R1 0→1 的 HarmRate 为 NA（深度 0 无正确序列，final-only 监督使浅层不是合格预测器）——与监督归因结论一致。
3. 阶段五撤回的两项结论维持撤回；本表为唯一有效的转移证据（bit-exact 复现模型的逐样本统计）。

## 2. 任务 3：错误类型学（`results/cogs_wrong_wrong_error_taxonomy.csv`，多标签）

R1@e3（每种子 ~14,415 错误序列，3 种子标签合计）：variable_index_error 15,194、predicate_or_role_error 12,824、bracket 5,593、truncation/no-EOS 3,652、other 27,960。

**按类别（R1@e3, 3 种子）**：
- **obj_pp_to_subj_pp**（干净结构失败，gold≤140）：3,000 样本中标签计数——variable_index 11,650、predicate/role 11,475、bracket 3,594、截断 1,654。**该类失败的近全数样本（~99%）含变量索引错误**——结构泛化失败的主导模式确认为变量索引跟踪，与 Lindemann et al. 需显式排列预测的结论一致。截断仅 1,654/3,000（~55% 样本量级），非主导。
- **cp_recursion**：variable_index 11,884 + 截断 4,178——索引错误与长度混杂并存（66.7% 样本超解码上限），两类失败叠加。
- 深度方向性：R1 从 e0→e3，variable_index 错误标签从 57,261 降至 15,194（额外递归大幅减少索引错误）、截断从 10,222 降至 3,652——递归修复的主要正是这两类。
- R2 各深度错误构成稳定（索引 ~15.5K、谓词 ~13.9K），与深度平坦的准确率一致。

## 3. 修订后的完整研究结论（当前证据边界）

1. **保留**（首次评估 + bit-exact 复现双重支撑）：R1@e3 比 E0W +10.7pp、R2 +9.2pp（gen，3 种子方向一致）；收益集中在词汇泛化类别；结构类全零。
2. **修订**：额外递归**不是**零破坏——2→3 深度的破坏率 4.7–13.9%（序列级），深度增加伴随边际修复递减与破坏率上升。深度选择的权衡真实存在（这恰好使"何时停止"成为真问题，为 gate 研究提供了此前缺失的动机，但 gate 确认需新保留集）。
3. **新机制结论**：递归修复的主要错误类型是变量索引与截断；obj_pp_to_subj_pp 的失败由变量索引主导（~99% 错误样本含索引错误）。
4. **限制**：E0/E0W 无逐样本预测（无法构造原始配对差值的逐样本版）；cp/pp_recursion 的 EM 仍受长度上限混杂（提高 max_len 的敏感性分析待批）；本阶段全部为对已解封 gen 的事后诊断。
